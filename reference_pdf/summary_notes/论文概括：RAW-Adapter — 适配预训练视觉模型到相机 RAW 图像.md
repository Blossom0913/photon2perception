# 论文概括：RAW-Adapter — 适配预训练视觉模型到相机 RAW 图像

## 一、研究背景与动机

Cui 和 Harada (2025) \[1] 来自东京大学和 RIKEN AIP，提出 **RAW-Adapter**，旨在解决**将 sRGB 预训练模型适配到相机 RAW 数据**的问题。

### 1.1 现有研究的两大主线

作者指出，利用 RAW 图像进行计算机视觉任务有两条主要技术路线 \[1]：

1.  **第一类方法**：保留传统 ISP 模块化设计，通过优化算法（如 CMA-ES）使其可微，如 Hardware-in-the-loop \[48]

2.  **第二类方法**：用神经网络完全替代 ISP 部分，如 Dirty-Pixel \[18] 使用 UNet 残差栈然而，这两类方法都将 ISP 和后端网络视为**两个独立的模块，缺乏交互能力**。

### 1.2 核心问题

Cui 和 Harada (2025) \[1] 在 Fig. 2 中通过实验表明：

*   用 RAW 数据从零训练会**显著降低性能**

*   使用 sRGB 预训练权重（如 COCO 或 ImageNet）带来巨大收益

*   因此核心问题是：**如何有效将信息丰富的 RAW 数据适配到知识丰富的 sRGB 预训练模型？**

### 1.3 sRGB 预训练模型的瓶颈

sRGB 成为当前主流选择原因包括 \[1]：

1.  **可扩展性**

2.  **易于存储**

3.  **ISP 各步骤多数为病态问题，依赖先验信息**然而，**ISP 是为人类视觉优化的，而非下游视觉任务**。许多商业 ISP 是黑盒，难以获取内部步骤信息，在某些条件下甚至不如直接使用 RAW \[22, 27, 40, 81]

## 二、相关工作

### 2.1 图像信号处理器（ISP）

Cui 和 Harada (2025) \[1] 综述了 ISP 的发展：传统 ISP \[16, 35, 51, 56] 包含去马赛克、白平衡、噪声去除、色调映射、色彩空间变换等模块。Heide 等 \[26] 设计的 FlexISP 组合多个 ISP 块进行联合优化；Chen 等 \[6] 提出的 SID 使用 UNet 替代传统 ISP 步骤将低光 RAW 转换为正常光 sRGB。

### 2.2 基于 RAW 数据的计算机视觉

早期方法直接对 RAW 执行任务 \[3, 81]，但**忽略了相机噪声**，且从零训练会放弃 sRGB 大规模预训练模型。后续研究专注于 ISP 与后端模型的集成 \[18, 22, 48, 55, 69, 72, 73, 75]。Wu 等 \[69] 提出 VisionISP，强调人眼视觉与机器视觉的差异。

### 2.3 计算机视觉中的适配器

Cui 和 Harada (2025) \[1] 指出，适配器在 NLP 领域广泛应用 \[28, 63]，在计算机视觉领域也被用于增量学习 \[31] 和域适应 \[57]，以及视觉模型 \[8, 33, 36] 或视觉-语言模型 \[65, 77]。RAW-Adapter 进一步扩展了适配器在 RAW 图像与 sRGB 预训练模型对齐中的应用。

## 三、核心方法：RAW-Adapter

### 3.1 输入级适配器（Input-level Adapters）

Cui 和 Harada (2025) \[1] 的输入级适配器设计如下，包含以下核心组件：

#### 3.1.1 查询自适应学习（QAL）

QAL 模块 $P_K$ 和 $P_M$ 用于预测 ISP 各阶段的关键参数。具体流程 \[1]：

1.  输入图像  $I_{i \in (1,2)}$  经过 2 个下尺度卷积块生成特征

2.  特征再经过 2 个线性层生成注意力的 key 和 value

3.  query 是一组可学习的动态参数

4.  通过自注意力计算 \[66] 预测 ISP 参数： $\text{parameters} = \text{FFN}(\text{softmax}(\frac{Q \cdot K^T}{\sqrt{d}}) \cdot V)$

#### 3.1.2 增益与去噪（Gain & Denoise）

为适应不同光照场景下的噪声抑制，$P_K$ 预测 \[1]：

*   **增益比 g** \[2, 6]：适应不同光照条件

*   **自适应各向异性高斯核 k**：抑制各种噪声条件，主轴  $r_1$  和副轴  $r_2$  由  $P_K$  预测（角度  $\theta$  设为 0 简化）

*   **滤波参数$\sigma$**（初始化为 0，Sigmoid 激活限制在 (0,1)）：保持锐度恢复细节**关键公式** \[1]： $k(x,y) = \exp(b_0 x^2 + 2b_1 xy + b_2 y^2)$  $I'_2 = (g \cdot I_1) \circledast k, \quad I_2 = I'_2 + (g \cdot I_1 - I'_2) \cdot \sigma$

#### 3.1.3 白平衡与 CCM 矩阵

受 Shades of Gray (SoG) \[20] 算法启发，使用可学习的 Minkowski 距离参数 $\rho$ 替代灰度世界的 L-1 平均 \[1]： $m_{i \in (r,g,b)} = \frac{\sqrt[\rho]{\text{avg}(I_2^\rho)}}{\sqrt[\rho]{\text{avg}(I_2^\rho)_{i}}}$ $I_2$ 乘以白平衡矩阵生成 $I_3$，再乘以 CCM 矩阵 $E_{ccm}$（初始化为单位矩阵 $E_3$，$P_M$ 预测的 9 个参数加到 $E_3$）生成 $I_4$。

#### 3.1.4 颜色操作（NILUT）

颜色操作过程通过查找表（LUT）实现。Cui 和 Harada (2025) \[1] 使用最新的神经隐式 3D LUT（NILUT）\[11]，通过 MLP 网络将输入像素强度 (R, G, B) 映射到输出 (R', G', B')： $I_5(R', G', B') = L(I_4(R, G, B))$ **参数优化**：为节省内存占用，将 NILUT 通道数从 128 改为 32 \[1]

### 3.2 模型级适配器（Model-level Adapters）

Cui 和 Harada (2025) \[1] 指出，ISP 各阶段的信息（$I_1 \sim I_4$）几乎被忽略。模型级适配器 $M$ 充分利用这些先验信息：

1.  使用卷积层  $c_i$  从  $I_1 \sim I_4$  提取特征

2.  拼接特征  $C(I_{1 \sim 4}) = \text{Concat}(c_1(I_1), c_2(I_2), c_3(I_3), c_4(I_4))$

3.  经过两个残差块生成适配器特征  $f_1$

4.  $f_1$  通过合并块与骨干网络 stage 1 特征融合

5.  合并块输出 stage 2 的网络特征和额外适配器  $f_2$

6.  过程在 stage 2 和 stage 3 重复

### 3.3 参数效率

Cui 和 Harada (2025) \[1] 报告了各部分的参数数量（Fig. 4 右）：

| 模块          | 参数量               |
| ----------- | ----------------- |
| $P_K$       | 37.57K            |
| $P_M$       | 37.96K            |
| $L$（NILUT）  | 1.97K             |
| $M$（模型级适配器） | 114.87K ~ 687.59K |
| **总参数**     | **约 0.2M ~ 0.8M** |


作为对比，SID \[6] 为 11.99M，Dirty-Pixel \[18] 为 4.28M，ResNet-50 \[25] 约 25.6M，Swin-L \[45] 约 197M。RAW-Adapter **参数数量远小于现有 SOTA 方法**

## 四、实验设置

### 4.1 数据集

Cui 和 Harada (2025) \[1] 在目标检测和语义分割任务上进行了实验（Table 1）：

| 数据集                        | 任务   | 数量     | 类型                 | 传感器                  |
| -------------------------- | ---- | ------ | ------------------ | -------------------- |
| PASCAL RAW \[52]           | 目标检测 | 4,259  | 真实                 | Nikon D3200          |
| PASCAL RAW (dark/over-exp) | 目标检测 | 4,259  | 合成                 | -                    |
| LOD \[27]                  | 目标检测 | 2,230  | 真实                 | Canon EOS 5D Mark IV |
| ADE20K RAW                 | 语义分割 | 27,574 | 合成（用 InvISP \[71]） | -                    |
| ADE20K RAW (dark/over-exp) | 语义分割 | 27,574 | 合成                 | -                    |


**合成方法**：基于以下物理噪声模型 \[1]： $y = l \cdot x + x_n, \quad x_n \sim \mathcal{N}(\mu = 0, \sigma^2 = \sigma_r^2 + s \cdot l \cdot x)$ 其中 $l$ 为光照强度参数，PASCAL RAW (dark) 随机从 \[0.05, 0.4] 选择，PASCAL RAW (over-exp) 从 \[1.5, 2.5] 选择。

### 4.2 实施细节

Cui 和 Harada (2025) \[1] 基于 mmdetection \[7] 和 mmsegmentation \[12] 构建框架：

*   **目标检测**：RetinaNet \[43]、Sparse-RCNN \[64] + ResNet \[25] 骨干

*   **语义分割**：Segformer \[70] + MIT \[70] 骨干（MIT-B5、B3、B0）

*   **预训练**：均使用 ImageNet 预训练权重

*   **优化器**：目标检测用 SGD（单卡 Tesla V100），语义分割用 Adam（4 卡 Tesla V100）

### 4.3 对比方法

Cui 和 Harada (2025) \[1] 与多种 ISP 方法和联合训练方法对比：

*   **传统 ISP**：Karaimer et al. \[35]

*   **网络 ISP**：InvISP \[71]、Lite-ISP \[79]、SID \[6]（低光）、DNF \[34]（低光）

*   **联合训练**：Dirty-Pixel \[18]
