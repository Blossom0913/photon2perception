# 论文概括：Ke 等 (2024) \[1] — 面向 RAW 与 HDR 图像的恢复任务神经网络训练策略研究

## 一、研究背景与动机

Ke 等 (2024) \[1] 来自剑桥大学和 Meta，发表于 CVPR Workshop 的论文围绕一个关键问题展开：**当神经网络的训练数据是线性色彩空间中的 RAW 或 HDR 图像时，应该如何选择像素编码方式和损失函数？**

### 1.1 现状分析

当前绝大多数在线图像与视频内容都表示为**显示编码（display-encoded）色彩空间**（如 BT.709 + sRGB 非线性）\[1]，其中像素值被缩放到 (0,1) 范围，且色彩分布近似感知均匀。然而：

*   **RAW 图像**直接来自传感器，保留未处理、未压缩的像素数据，为恢复技术提供丰富信息 \[1]

*   **HDR 图像**通常在线性色彩空间中表示，像素值与光度/辐射度量呈线性关系

*   两种图像所在的**线性色彩空间非常不感知均匀**：相同的物理变化在低亮度处比高亮度处可见得多（韦伯定律）\[1]

*   现代感知均匀传递函数包括 **SMPTE PQ（perceptual quantizer）**\[21] 和 **PU21（perceptually uniform transform）**\[18] 等

### 1.2 关键问题

现有文献存在两大未解问题：

1.  **像素表示问题**：HDR/RAW 图像是否需要通过 PQ、PU21 或 μ-law 等显示编码函数进行感知编码？

2.  **损失函数问题**：如果在线性空间训练，是否应使用补偿感知非均匀性的损失函数？部分工作 \[6, 7, 28] 在线性色彩空间直接使用 L1 损失训练，而另一些工作 \[8, 13, 20] 使用感知编码损失。**没有任何研究系统对比这些策略在不同任务和架构上的效果**

## 二、相关工作

### 2.1 RAW 像素处理

Ke 等 (2024) \[1] 指出，RAW 图像保留未处理像素数据，**有利于物理可信的相机噪声建模** \[1]。早期工作 \[10, 12] 基于统计噪声模型，深度学习时代 \[4, 22, 26] 开启了去噪新范式。但**许多 RAW 处理方法实际上在 sRGB 空间训练，假设加性高斯噪声**，与真实相机 RAW 数据差异巨大 \[1]

### 2.2 HDR 成像

HDR 涉及多曝光合并（去鬼影）\[13]、色调映射 \[23]、单曝光 HDR 重建 \[8, 14] 等任务。在标准重建任务（去噪、超分、去模糊）方面：

*   Eilertsen 等 \[8] 和 Kalantari 等 \[13] 在线性空间训练 HDR 图像，前者使用对数损失，后者引入 μ-law
*   Mildenhall 等 \[20] 在 RAW 图像训练 NeRF 时使用类似 SMAPE 的相对损失
*   Kim 等 \[14] 直接用 PQ OETF 训练 HDR UHD 视频重建

## 三、核心方法：八种训练策略组合

### 3.1 像素编码方式（4 种）

Ke 等 (2024) \[1] 测试了 4 种像素表示：

| 编码方式       | 描述                                                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Linear** | BT.709 primaries 的线性 RGB，像素值缩放到 0-1 范围                                                                                                 |
| **μ-law**  | 公式$v_\mu(l) = \log(1 + \mu l) / \log(1+\mu)$，$\mu=5000$，常用于感知音频编码 \[13]                                                                |
| **PQ**     | SMPTE 感知量化器 \[21]，HDR 内容显示编码标准（BT.2100），按通道编码绝对单位值（0.005-4000 cd/m²）                                                                   |
| **PU21**   | 基于更现代感知数据开发的变换 \[18]，$v_{PU21}(L) = a(\log_2 L - L_{min})^2 + b(\log_2 L - L_{min})$，其中$a=0.001908$，$b=0.0078$，$L_{min}=\log_2(0.005)$ |


**关键差异** \[1]（图 1）：

*   PQ 和 PU21 形状相似，但 PQ 在最小值 0.005 处未达到 0

*   μ-law 在 1 以下斜率较缓，对低值编码精度较低

*   **Linear 在大像素值处斜率过陡，过度强调亮区**（x 轴为对数刻度）

### 3.2 损失函数

Ke 等 (2024) \[1] 测试的 8 种组合如下：

| 标签           | 像素编码   | 损失函数               |
| ------------ | ------ | ------------------ |
| Linear-L1    | Linear | L1                 |
| PQ-L1        | PQ     | L1                 |
| PU21-L1      | PU21   | L1                 |
| μ-L1         | μ-law  | L1                 |
| Linear-PQ    | Linear | PQ                 |
| Linear-PU21  | Linear | PU21               |
| Linear-μ     | Linear | μ-law              |
| Linear-SMAPE | Linear | SMAPE（对称平均绝对百分比误差） |


SMAPE 公式： $\text{!} = \left\|\frac{|f_\phi(x) - y|}{|f_\phi(x)| + |y| + \epsilon}\right\|_1$ 所有感知编码因已近似感知均匀，故统一使用 L1 损失 \[1]。同时还测试了 L1 与 PQ 编码 L1 之和等组合，**但其性能不优于单独的损失项**

## 四、实验设置

### 4.1 数据集

**HDR 数据集** \[1]：

*   106 张 HDR 图像（HDR Photographic Survey \[9] + SJTU HDR Video Sequences \[24]）

*   60% 训练、20% 验证、20% 测试

*   测试集通过 0.1-0.9 之间的随机曝光系数增强 5 倍

*   添加物理可信的模拟相机噪声（光子噪声 + 读出噪声）\[10]**RAW 数据集** \[1]：

*   "Learning to See in the Dark" 数据集 \[6] 的 231 张长曝光 RAW 图像

*   同样 60/20/20 划分

*   通过 AHD 去马赛克 \[11] 重建颜色值，转换为 BT.709 线性空间

*   平均亮度调整为 20 nits 以匹配 SDR 内容平均亮度**注**：由于计算限制，仅超分方法在 RAW 数据集上测试 \[1]

### 4.2 神经网络与训练任务

Ke 等 (2024) \[1] 选择 6 种网络，每任务 2 个：

| 任务            | 网络 1                | 网络 2                     |
| ------------- | ------------------- | ------------------------ |
| 超分（4×）        | EDSR (2017) \[15]   | Real-ESRGAN (2021) \[25] |
| 去模糊（高斯模糊 σ=8） | GFNNet (2018) \[32] | MirNet-v2 (2022) \[30]   |
| 去噪            | DnCNN (2017) \[31]  | SADNet (2020) \[5]       |


所有方法均按原作者 GitHub 仓库代码训练，**Real-ESRGAN 仅使用 L1 损失（禁用感知损失）**。训练 epoch 数：EDSR 3000、Real-ESRGAN 150、其余 1000 \[1]

### 4.3 评估指标

Ke 等 (2024) \[1] 使用三种指标：

*   **PSNR**：在 PU21 编码的 RGB 像素上计算

*   **SSIM**：在 PU21 编码像素的亮度通道上计算

*   **ColorVideoVDP**：原生支持 HDR 图像，专为颜色图像和视频设计 \[19]配对 t 检验（双尾，α=0.05，HDR N=144、RAW N=276）评估统计显著性

## 五、实验结果

### 5.1 超分任务（Figure 3 & Table 2）

**HDR 超分（EDSR）**：

| 配置           | PSNR      |
| ------------ | --------- |
| PU21-L1      | **33.04** |
| μ-L1         | 33.03     |
| PQ-L1        | 32.81     |
| Bilinear（基线） | 30.14     |
| Linear-L1    | 28.10     |
| Linear-μ     | 27.71     |
| Linear-PU21  | 27.31     |
| Linear-PQ    | 26.62     |
| Linear-SMAPE | 22.37     |


**关键发现** \[1]：

*   使用感知像素表示相比 Linear-L1 带来 **1.5-9 dB** 显著增益

*   **三种感知编码（PU21-L1、PQ-L1、μ-L1）之间无统计显著性差异**

*   感知损失函数（除 ESDR-RAW 实验外）相比 Linear-L1 未提升结果

*   Linear 表示训练的网络常出现**颜色伪影**（图 S2、S3）**RAW 超分（Real-ESRGAN）**：

*   PQ-L1 取得最佳 PSNR=35.21

*   Linear-PU21 表现最差（PSNR=18.50）

*   感知编码再次显著优于 Linear-L1（PSNR 33.70 vs Linear-L1）

### 5.2 去模糊任务（Figure 4 & Table 2）

**GFNNet** \[1]：

*   在多种损失函数配置下**训练失败或无法收敛**

*   仅感知像素编码全部收敛

*   μ-law 取得最佳 PSNR=33.65，其次 PU21-L1（33.52）

*   Linear-L1 相比最优提升 **约 3.8 dB**

*   Linear-L1 出现**垂直条纹伪影**（图 S4），PQ-L1 图像略柔和**MirNet-v2**：

*   优于 GFNNet

*   Linear-μ 取得最佳 PSNR=34.80

*   PU21 表现相对较差（图 S5 图像略柔和）

### 5.3 去噪任务（Figure 5 & Table 2）

**DnCNN** \[1]：

*   μ-L1 取得最佳 PSNR=23.65

*   Linear-L1 仅 PSNR=17.93

*   DnCNN 输出的图像**亮度、色调、色彩、对比度**与原图有偏差，**PSNR 对此敏感**

*   ColorVideoVDP 和 SSIM 更关注结构失真，与感知质量相关性更好**SADNet**：

*   ColorVideoVDP 无法区分任何配置（无统计差异）

*   μ-law 一致性最高，PU21 第二佳（SSIM）

*   Linear-PQ 和 Linear-PU 出现**颜色偏移**，导致 PSNR 低于输入噪声图像（但 ColorVideoVDP 仍较高）

## 六、核心结论与最佳实践

Ke 等 (2024) \[1] 通过 6 种方法在 3 个任务上的系统实验，得到清晰一致的结论：

### 6.1 主要结论

1.  **强烈推荐使用感知变换（PU21、PQ 或 μ-law）编码 HDR/RAW 图像进行训练**

2.  相比 Linear-L1 默认方法，**性能增益在 2-9 dB 之间**

3.  三种感知变换**无明确优劣之分**，可任意选择

4.  **在线性空间使用感知损失函数效果较差**，多数情况下并不优于 Linear-L1

### 6.2 各编码方式分析

| 编码        | 优势              | 劣势                       |
| --------- | --------------- | ------------------------ |
| **μ-law** | 跨方法稳健、公式简单、计算高效 | 不总是最佳结果                  |
| **PU21**  | 公式简单、感知基础更强     | 在 MirNet-v2 和 SADNet 上略差 |
| **PQ**    | 感知基础强、HDR 标准    | GFNNet 表现略差；无法缩放到 0-1 范围 |


### 6.3 理论解释

Ke 等 (2024) \[1] 推测感知变换之所以有益，是因为它们提供了**更好的数据效率**：

*   PU21、PQ、μ-law 编码像素需要**更少比特**表示相同视觉信息

*   网络理论上可学习这种变换，但这**会消耗网络容量**，削弱其在主要任务上的表现

## 七、核心贡献总结

Ke 等 (2024) \[1] 的研究主要贡献如下：

1.  **系统基准研究**：在 3 个图像恢复任务（去噪、去模糊、超分）上对比 6 种网络 × 8 种训练策略（编码 + 损失）组合

2.  **明确最佳实践**：通过大量实证证明 **HDR/RAW 图像应通过感知变换（PU21、PQ 或 μ-law）进行编码后再训练**

3.  **巨大性能提升**：相比默认 Linear-L1 训练策略，性能提升 **2-9 dB**

4.  **明确否定常见做法**：揭示在 RAW/HDR 图像处理中，**常见的 Linear-L1 训练策略效果不佳**，应作为反例而非默认

5.  **"一行代码"改进**：仅需在训练前进行感知编码，即可带来实质性的性能提升

## 八、局限性与未来方向

Ke 等 (2024) \[1] 指出，本文为基准研究，**未提供为什么感知变换有益的明确结论**。可能的解释是数据效率提升，但需要进一步研究。**许多实践者仍使用 Linear-L1 默认策略**，本文旨在提供明确指引以改进 HDR/RAW 图像的神经网络训练 \[1]

## 十、结语

Ke 等 (2024) \[1] 的工作**为 HDR 与 RAW 图像处理领域的训练策略提供了明确的最佳实践指引**。这一研究表明，**感知编码（PU21、PQ 或 μ-law）是训练 HDR/RAW 恢复网络的正确选择**，可带来 2-9 dB 的显著增益，且仅需"一行代码"修改。这一发现对低光照增强、HDR 重建、RAW 图像去噪/超分等众多应用场景具有直接的实践指导意义，将帮助从业者设计更好的 HDR/RAW 图像处理模型 \[1]
